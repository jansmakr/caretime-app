## 2026-10-01

- `f103e91` 병원 요청을 비공개로 받고, 지금 할 수 있는 것(지역 글)을 알려준다

- 8-a 준비. 운영 적용 순서 문서, 공공데이터 스키마 초안(미적용), 중복 방지 키, 수동 입력 받을 자리
- 좌표를 1차에서 뺐다. 강서구 달빛어린이병원 2곳 투입. DEMO 배너가 실제 병원을 가상이라 말하던 것 수정
- 병원 상세의 제보를 현장톡으로 합쳤다. 브라우저에만 남던 두 번째 저장소를 지웠다
- 1차 범위를 좁혔다. 어긋난 항목별 상태·진료시간·병원 화면을 내리고 현장톡을 홈의 유일한 주 동작으로
- /terms·/privacy 라우트와 하단 링크 자리. policy_version 형식은 terms=날짜;privacy=날짜
- 서버가 읽은 글이 첫 HTML 부터 보인다. 격리된 글은 되살아나지 않는다
- 작성창 기본값을 상처 질문에서 뺐다. 기본 칩 '그 밖의 상황', 본문 비움, 주제 선택
- 1차 점검 목록을 끝까지 소화. 남은 것은 약관·방침 본문, 운영 DB 적용, 진료시간 2곳뿐
- 보관 기간 표를 방침에 옮겨 적을 수 있게 다시 썼다. 삭제 방식·테스트 유무까지. 진료시간·공공데이터는 1차 이후로
- 본인이 쓴 글을 지우는 기능. 남의 글은 지워지지 않는다. 서버가 내 글 id 를 읽어 첫 그림부터 삭제 버튼이 붙는다
- 삭제 테스트의 빈칸을 채웠다(reports·moderation_actions·observations). 미처리 신고 90일 자동 종결 + 크론 상태 조회

- 운영 적용 직전 점검 목록(체크박스 41개)과 리허설 절차. 수동 병원 SQL 생성(npm run sql:manual-hospitals)
