### 3. DEMO 배너를 뗄 수 있는 조건

배너는 이제 `isDemoContentAllowed` 가 켜져 있을 때만 붙는다(`components/common/DemoNotice`).
운영 빌드에서는 그 플래그가 기본으로 꺼지므로 **배너가 없다.**

그래서 남은 질문은 "배너를 떼도 되는가" 가 아니라 **"그 플래그를 꺼도 되는가"** 다.
조건은 셋이고, 셋 다 "화면에 가짜가 안 나오는가"를 묻는다.

| 조건 | 상태 |
|---|---|
| 화면에 나가는 병원이 전부 실제 데이터 | **아직.** `supabase/seed.sql` 의 가상 5곳이 로컬에 있다. 운영에는 들어가지 않지만, 운영 DB 에 실제 병원이 들어가야 목록이 빈다 |
| 가상 제보·가상 대화가 안 나온다 | ✅ `showDemoReports` 가 같은 플래그를 따른다. 운영에서 0건 |
| 공식 출처 배지가 근거 없이 안 붙는다 | ✅ `showOfficialSourceBadge` 가 같은 플래그. 승인된 병원이 0곳이라 어차피 안 붙는다 |

즉 **운영 DB 에 실제 병원을 넣는 순간 플래그를 끌 수 있다.** 그 전에 켜 두면 가상
병원이 나오고, 끄면 목록이 빈다 — 둘 다 나쁘다. 그래서 병원 데이터가 선행 조건이다.

확인 방법: 운영 빌드를 띄워 `/chat`·`/search` HTML 에 `가상` 이 없는지 본다.
