## DEMO 플래그를 끌 수 있는 조건

배너는 `isDemoContentAllowed` 가 켜져 있을 때만 붙고(`components/common/DemoNotice`),
운영 빌드에서는 **기본으로 꺼진다.** 그래서 남은 질문은 "배너를 떼도 되는가"가 아니라
**"가짜가 화면에 안 나오는가"** 다.

| 조건 | 상태 |
|---|---|
| 화면에 나가는 병원이 전부 실제 데이터 | 운영 DB 에 `seed.sql` 을 넣지 않고 수동 2곳만 넣으면 충족된다 |
| 가상 제보·가상 대화가 안 나온다 | 같은 플래그를 따른다. 운영에서 0건 |
| 공식 출처 배지가 근거 없이 안 붙는다 | 승인된 병원이 0곳이라 어차피 안 붙는다 |

확인 방법: 운영 빌드를 띄워 `/chat`·`/search` HTML 에 `가상` 이 없는지 본다.
