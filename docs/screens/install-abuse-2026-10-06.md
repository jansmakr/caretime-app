# 홈 화면 바로가기 · 욕설 거르기 — 2026-10-06

## ① 홈 화면 바로가기 (PWA)

### 어디에 보이는가

- **홈 맨 아래 한 줄.** 배너로 키우지 않았다 — 처음 온 사람이 하려는 일은 글을
  읽는 것이고, 바로가기는 그 사람이 **다시 올 때** 쓸모가 생긴다(원칙 1).
- **더보기 메뉴에 같은 항목.** 홈에서 × 로 닫은 사람이 마음을 바꿨을 때 찾아올
  자리다. 여기에는 닫는 버튼이 없다.

```
[홈 맨 아래]
┌─────────────────────────────────────────┐
│ 홈 화면에 추가 · 다음에 아이콘 하나로 바로 열 수 있습니다  [추가] [×] │
└─────────────────────────────────────────┘
```

### 브라우저마다 다르게 그린다

| 어디 | 무엇이 보이는가 |
|---|---|
| 안드로이드 크롬 | 한 줄 + **[추가]** 버튼 (`beforeinstallprompt`) |
| 아이폰 사파리 | 한 줄 + "공유 버튼 → '홈 화면에 추가'" **안내만.** 버튼을 만들 수 없다 |
| 이미 설치됨 (`display-mode: standalone`) | 아무것도 안 그린다 |
| 데스크톱·그 밖 | 아무것도 안 그린다 |

버튼을 만들어 두고 눌러도 아무 일이 없게 하지 않는다. iOS 에는 `beforeinstallprompt`
가 없어서 설치를 코드로 띄울 수 없다 — 그래서 iOS 에는 안내만 둔다.

### 닫으면 다시 안 뜬다

`localStorage.caretime_install_dismissed`. 매번 묻는 안내가 가장 빨리 미움받는다.
더보기 메뉴에는 그대로 남으므로 길이 막히지는 않는다.

### 설치하면 어디가 열리는가 — **`/chat`**

홈이 아니다. 아이콘을 만든 사람은 이미 이 서비스가 무엇인지 알고, 급할 때 필요한
것은 방이다(원칙 1·5). 주소창 없이 열린다(`display: standalone`).

### 넣지 않은 것

- **푸시 알림** — 보낼 곳(구독 토큰)을 저장해야 하고 방침이 바뀐다. 2차에 로그인과
  함께(docs/LAUNCH-scope.md).
- **오프라인 캐시(service worker)** — 오래된 글을 최신인 양 보여 줄 수 있다.
  이 서비스에서 가장 하면 안 되는 일이다. 네트워크가 없으면 없다고 보이는 쪽이 맞다.

### 확인

로컬은 http 라 설치가 돌지 않는다. manifest·아이콘이 응답하는 것까지만 봤다.

```
/manifest.webmanifest  200  start_url "/chat"
/icon-192.png          200  3,192B
/icon-512.png          200  12,158B
/icon-maskable-512.png 200  11,568B   (안드로이드가 모양대로 깎는다. 여유 판)
/apple-touch-icon.png  200  2,929B    (iOS 는 manifest 아이콘을 안 본다)
```

설치 흐름은 배포 뒤 `*.vercel.app` 에서 본다 — `docs/DEPLOY-order.md` I절에 항목을
넣었다.

## ② 욕설 거르기

### 작성창에 보이는 것

```
직접 확인한 사실만 적어 주세요. 진단이나 치료 판단은 적지 않습니다.
의료기관·의료진을 비방하는 글, 욕설은 올릴 수 없습니다.     ← 굵게
```

둘째 줄이 억제력의 대부분이다. 쓰려다 보고 멈추게 하는 것이 목적이다.
**"차단됩니다"로 쓰지 않았다** — 문맥 비방은 실제로 통과하므로 거짓이 되고,
거짓인 경고는 다음 경고까지 안 읽히게 만든다.

### 실제로 돌려 본 것 (운영 빌드, 422)

| 보낸 글 | 결과 |
|---|---|
| "여기 진짜 병신같은 병원이네요" | **422** · `'병신' 은(는) 올릴 수 없습니다. 그 표현을 빼고 다시 올려 주세요.` |
| "대기가 두 시간이었습니다. 접수 안내가 불친절했어요." | 200 — 불만은 욕이 아니다 |
| "발병 신고는 어디에 하나요? 새끼손가락을 다쳤습니다." | 200 — 오탐 후보가 통과한다 |

### 무엇이 걸렸는지 말한다

전에는 어떤 거절이든 화면에 "보내지 못했습니다. 잠시 후 다시 시도해 주세요."만
떴다. 서버가 보낸 이유가 `catch` 에서 버려지고 있었다 — 개인정보가 걸린 것인지,
욕설인지, 서버가 죽은 것인지가 전부 같은 문장이었다.

4xx(= 글을 고치면 되는 거절)는 `ReportRejectedError` 로 구분해 **서버가 적어 보낸
문장을 그대로** 보여 준다. 5xx·네트워크 실패만 "잠시 후 다시" 로 남는다.

### 못 막는 것 — 알고 간다

"○○병원 불친절해요"에는 욕이 한 글자도 없다. 기계가 가릴 수 없고, 가리려 하면
정상 후기까지 막힌다. 이 서비스는 "가보니 어땠나요"를 묻는 곳이라 그쪽 손해가
훨씬 크다. 신고 → 격리가 맡는다. `abuse.test.ts` 가 **이 한계를 테스트로 고정**
한다 — 구멍이 아니라 의도한 선이다.

공백으로 쪼갠 것("ㅅ ㅂ")과 글자를 끼운 것("씨이이이발")도 통과한다. 공백을 지우면
"발병 신고"가 '병신'에 걸리고, 모음을 지우면 멀쩡한 낱말이 부서진다.
**거르지 못한 것보다 멀쩡한 글을 막는 것을 더 큰 손해로 본다.**

## ③ 소식 듣기 — 1차에 없다

내 글에 답이 달려도 알림이 없다. 다시 들어와서 보는 것이 유일한 길이고, 그래서
홈 화면 바로가기를 만들었다. 2차에 로그인과 함께 연다 — 근거는
`docs/LAUNCH-scope.md`.

# 푸터를 갈랐다 · 머리띠에 더보기 — 2026-10-06

## 어디에 무엇이 남았는가

| 화면 | 머리띠 | 맨 아래 |
|---|---|---|
| `/` 홈 | CareTime · **더보기** · 119 | 약관·방침 **한 줄**(14px) |
| `/chat` | 현장톡 · **더보기** · 119 | 없다 |
| `/more` | 더보기(자기 링크 없음) · 119 | 약관·방침 두 줄 → **사업자 정보** |

## 왜 갈랐는가 — 의무가 둘이고 서로 다르다

- **개인정보 처리방침 링크**는 홈에 남는다. 개인정보보호법 제30조 2항이
  "정보주체가 **쉽게 확인할 수 있도록**" 공개하라고 하고, 실무 기준은 첫 화면
  링크다. 메뉴 안으로만 옮기면 메뉴를 열고 또 들어가게 된다.
- **사업자 정보**는 `/more` 로 내려갔다. 전자상거래법의 초기화면 표시 의무는
  재화·용역을 **파는 곳**에 걸리고 CareTime 은 팔지 않는다.

둘을 같은 것으로 묶어 함께 옮겼으면 한쪽이 깨졌다.

## 글자 크기 12.5px → 14px

원칙 2 의 하한 아래였다. 법이 "쉽게 확인"이라고 할 때 읽히지 않는 크기면 취지가
살지 않는다. 사업자 정보 4줄이 빠져 자리가 생겼으므로 부담이 없다.

## 더보기는 서랍이 아니다

`/more` 로 보낸다. 서랍(오버레이·포커스 트랩·스크롤 잠금·ESC)은 한 번 읽는 내용에
붙이기에 큰 장치다(원칙 10). 그리고 열면 **약관·방침이 그 화면 맨 위 두 줄**이라
"메뉴를 열면 한 번에 보인다"가 그대로 지켜진다.

하단 고정 메뉴를 지운 결정과 어긋나지 않는다. 그때 지운 것은 아무 데도 가지 않는
문 네 개(찾기 → 404)와 화면 아래 60px 이었다. 이것은 머리띠 안 44px 하나이고
본문을 깎지 않는다. `/more` 자신에게는 자기 링크를 두지 않는다.

## 아이콘 — 말풍선 + 십자, `#1C5FD8`

파란 바탕 · 흰 말풍선 · 그 안의 파란 십자. 넣지 않은 것과 근거는
`docs/LAUNCH-scope.md` 에 적었다 — **ER·응급 표기 없음**(응급의료기관이 아니고
119 대신 눌리면 안 된다), **빨간 십자 없음**(적십자 표장은 법으로 보호된다),
글자 없음(작은 크기에서 안 읽히고 깎일 때 먼저 잘린다).

**사람이 그린 최종 파일 5개로 바꿨다**(2026-10-06). 치수와 바탕색을 확인하고
눈으로 본 뒤에 넣었다 — 바탕 `#1C5FD8`, 빨간 십자 없음, 글자 없음, ER 표기 없음.

| 파일 | 크기 | 쓰임 |
|---|---|---|
| `public/icon-192.png` | 192 | 설치된 바로가기 (manifest) |
| `public/icon-512.png` | 512 | 같음, 큰 판 |
| `public/icon-maskable-512.png` | 512 | 안드로이드가 모양대로 깎을 때 쓰는 여유 판. 보낸 파일명 `icon-512-maskable.png` 를 이 이름으로 바꿔 넣었다 |
| `public/apple-touch-icon.png` | 180 | iOS. manifest 아이콘을 안 본다 |
| `public/favicon-64.png` | 64 | **브라우저 탭.** manifest 대상이 아니라 `layout.tsx` 의 `icons.icon` 으로 건다 |

띄워서 확인했다 — 다섯 파일 전부 200, HTML 에 세 줄이 들어간다.

```
<link rel="icon" href="/favicon-64.png" sizes="64x64" type="image/png"/>
<link rel="apple-touch-icon" href="/apple-touch-icon.png"/>
<link rel="manifest" href="/manifest.webmanifest"/>
```

`scripts/gen-icons.mjs` 는 남겨 두되 **머리에 경고를 붙였다** — 아무 생각 없이
돌리면 최종 파일을 덮어쓴다. 치수·규칙 기준으로만 쓴다.

# 홈 화면 추가 안내 — 보탠 것 · 2026-10-08

기능 자체는 2026-10-06 에 들어갔다(위). 여기서 보탠 것만 적는다.

## 크롬 권장

안드로이드 문구 끝에 붙였다.

```
홈 화면에 추가 · 다음에 아이콘 하나로 바로 열 수 있습니다 · 크롬 권장
```

일부 안드로이드 브라우저로 설치하면 구글 **Play 프로텍트 경고**가 뜨고, 설치하려던
사람이 거기서 멈춘다. 우리가 없앨 수 없는 화면이라 미리 한 줄 적는 쪽이 싸다.

**iOS 에는 붙이지 않았다.** 사파리로만 설치되는 기기에 크롬을 권하면 길이 막힌다.

## 글자 14px

12.5px 로 만들어 두었는데 원칙 2 의 하한 아래였다. 내가 만든 코드라 부채로 넘기지
않고 올렸다. 줄이 한 줄 늘어나는 것은 받아들였다.

## 방침 1-4 — 기기에만 저장되는 것

닫은 선택(`caretime_install_dismissed`)이 브라우저에 남는데 방침에 없었다.
**같은 성격의 값이 하나 더 빠져 있었다** — 내 지역(`caretime_my_region`).
둘을 묶어 한 절로 넣었다. 서버로 가지 않는다는 사실을 함께 적었다.

## 겹치지 않는가

| | |
|---|---|
| 안내가 있는 화면 | `/` · `/more` |
| 작성창이 있는 화면 | `/chat` |

**같은 화면에 함께 있을 수 없다.** 그리고 안내는 `fixed`·`sticky`·`absolute` 가
없는 문서 흐름 안의 줄이라, 무엇을 덮을 수가 없다.

## 390px 가로 예산

| 차지하는 것 | 폭 |
|---|---|
| 홈 `main` 좌우 여백 (`px-5`) | 40px |
| 안내 좌우 여백 (`px-3.5`) | 28px |
| 사이 간격 (`gap-2` × 2) | 16px |
| [추가] 버튼 | 약 51px |
| [×] 버튼 (`h-11 w-11`) | 44px |
| **글자에 남는 폭** | **약 211px** |

글자 칸이 `min-w-0 flex-1 break-keep` 이라 넘치지 않고 **아래로 늘어난다**(3줄쯤).
고정 폭·`nowrap` 이 없다.
