# 6-a 직후 — 개인정보 필터 + 신고 자동 격리 (2026-09-29)

화면 변화는 작다. 바뀐 것은 대부분 서버에서 일어난다.

## 글을 쓸 때 — 개인정보가 섞이면 막힌다

```
전화번호로 보이는 숫자가 있습니다. 개인 연락처는 올릴 수 없습니다.
```

무엇이 걸렸는지 말한다. "올릴 수 없습니다"만 적으면 무엇을 고쳐야 할지 모른다.
여러 개가 걸려도 **하나만** 알린다 — 급한 사람에게 목록을 읽히는 것보다 하나를
고치게 하는 편이 빠르다(원칙 5).

| 막는 것 | 예 |
|---|---|
| 휴대전화·지역번호 | `010-1234-5678`, `01012345678`, `+82 10 1234 5678` |
| 주민등록번호 모양 | `900101-1234567` |
| 이메일 | `aaa@bbb.com` |
| 카드·계좌 길이 숫자 | `1234 5678 9012 3456` |

**막지 않는 것**: 이름처럼 보이는 문자열(한국어 이름은 일반 낱말과 구분되지 않는다),
시각·인원 같은 짧은 숫자, **그리고 병원 대표번호**.

병원 번호는 아는 번호만 통과한다. "병원 번호처럼 보이면 통과"로 만들면 개인 번호를
병원 번호인 척 적을 수 있다.

## 글마다 — 신고

```
[ 👍 대기 3명 이하 ]  [ 🩺 선생님 계심 ]  [ ⚠️ 접수 마감됨 ]

이 의료기관 정보 보기 ›          [신고]  [공유]
```

누르면 바로 접수되지 않는다. 이유를 한 번 고르게 한다.

```
어떤 점이 문제인가요?
접수되면 이 글은 바로 보이지 않게 됩니다. 확인 후 복구될 수 있습니다.

  [ 개인정보가 적혀 있어요 ]
  [ 사실과 달라 보여요 ]
  [ 위험한 조언이에요 ]
  [ 욕설·비방이에요 ]
  [ 광고예요 ]
  [ 그 밖의 이유 ]
  [ 취소 ]
```

한 단계를 두는 이유는 둘이다. 신고가 즉시 글을 내리므로 잘못 눌러 남의 글이 사라지는
일을 막아야 하고, 운영자가 복구를 판단할 때 "왜 신고됐는지"가 있어야 한다.

접수 후:

```
신고했습니다. 확인할 때까지 이 글은 보이지 않습니다.
```

내 글에는 신고 버튼이 없다. 지우는 경로는 아직 없다 — 별도 작업이다.

## 서버에서 일어나는 일

1. 신고 접수 → DB 트리거가 **즉시** `visibility = 'QUARANTINED'`
2. 그 변경이 broadcast 로 전파 → 그 방을 **열어 둔 모든 사람**의 화면에서 사라짐
3. `moderation_actions` 에 기록 (`action=QUARANTINE`, `reason_code=auto_on_report`,
   `actor_id=null` — 사람이 아니라 규칙이 내렸다)

사람이 보기 전에 내려간다. 신고는 새벽에 들어오고 운영자는 자고 있다.

같은 사람이 다시 신고해도 기록이 부풀지 않는다. 이미 내려간 글은 다시 내리지 않는다 —
기록이 부풀면 "몇 명이 신고했나"를 셀 때 틀린다.

## 운영자가 하는 일 (콘솔)

`/admin` 은 만들지 않았다. SQL 은 migration `20261001` 맨 아래에 적어 뒀다.

- 새 신고 보기 — `reports` 와 `field_reports` 조인
- 복구 — `visibility = 'VISIBLE'` + `reports.state = 'DISMISSED'` + `RESTORE` 기록
- 완전 삭제 — `visibility = 'REMOVED'`. **행을 지우지 않는다** — 지우면 같은 사람의
  다른 글을 찾을 수 없다

⚠️ 복구해도 이미 화면을 닫은 사람에게는 다시 가지 않는다. 다시 열면 보인다.

## 받아들인 위험

**악의적 신고 하나로 멀쩡한 글이 내려간다.** 이걸 받아들인 이유는 비대칭이다 —
잘못 내린 글은 복구하면 돌아오지만, 잘못 남긴 글은 읽힌 것을 되돌릴 수 없다.
신고 자체에 시간당 5건 제한이 걸려 있고, 신고도 서버 라우트만 받는다(anon 에게 열면
신고가 도배 수단이 된다).

운영하며 지켜봐야 한다. 정상 글이 자주 내려가면 임계치를 2건으로 올린다.
`docs/OPEN-QUESTIONS.md` 에 적어 뒀다.
