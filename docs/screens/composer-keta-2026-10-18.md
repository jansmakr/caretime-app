# 작성창 안내 축소 · 올리기 전 확인 2종 · 케타 · 119 확인 (2026-10-18)

코드·테스트·빌드로 확인했다. 휴대폰 확인 방법은 PR 본문에 있다.
위치 자동 요청은 이 단계에 없다(별도 PR feat/location-prompt-on-entry).

## 홈
- 맨 아래 의료기관 한 줄: 옅은 회색 바탕 줄(48px)에 "🏥 의료기관 담당자이신가요?"(진한 글자) ·
  "사전 신청 안내"(파란 글자, 밑줄). 현장톡 주 버튼보다 약하다

## 현장톡 맨 위
1. 노란 유의 문구(그대로)
2. **케타 말풍선** — 🧭 동그라미 + 말풍선
   - "케타" · 회색 칩 "AI 아님 · 정해진 안내만 해요"
   - "주변 분들이 눌러 준 빠른 반응으로 상황을 알 수 있어요. 답이 없을 수도 있어요. 급하면 119."
     (2026-10-24 교체. 전에는 "이웃 보호자가 답할 수 있지만…"과 신고하기 안내 문장이 있었다 —
     글로 답해 준다는 말이 사실과 달라 뺐고, 신고 안내 문장도 함께 빠졌다)
   - 연빨강 버튼(48px) "🚑 위급하면 기다리지 말고 119 전화" → **"119에 전화할까요?" 확인 시트**
     → [119 전화 걸기] / 닫기. 머리띠 119 버튼과 같은 창이다
   - 빈 방·조회 실패·글 0건 어느 상태에서도 같은 자리에 있다

## 작성창
- 🎤 버튼과 그 아래 한 줄(그대로)
- 입력칸 16px. 빈 칸 안내 "지금 상황이나 다녀온 곳을 적어 주세요. 병원 이름을 함께 적으면 더 도움이 됩니다."
- 입력칸 아래: 오른쪽에 "○자 남음"(14px)만. "이름과 연락처는 적지 마세요" 줄은 없다
- 회색 상자 한 줄(14px): "서울 강서구 · 차분한수달4821 이름으로 올라갑니다" / 안 골랐으면 "지역 없이 · …"
- [내 위치로 선택] 또는 [올라갈 위치 바꾸기] (그대로 — 누를 때만 위치를 묻는다)
- 올리기 위 한 줄(14px): "진단·치료 조언, 의료기관 비방·욕설은 적지 말아 주세요."
- [올리기]

## 올리기를 눌렀을 때 — 걸릴 때만 아래 시트
- **전화번호가 있을 때**: "전화번호가 적혀 있어요" / "글은 누구나 읽습니다. 개인 번호는 올라가지 않아요. 병원 이름을 적어 주시면 충분합니다."
  - [번호 지우기](주) → 번호만 지우고 입력칸으로 돌아간다. 바로 올라가지 않는다
  - "병원 대표번호예요 · 그대로 올리기" → 서버가 판정한다(아는 병원 번호는 통과, 아니면 거절 문구)
  - "고쳐 쓰기" → 닫힘
- **진단·치료 판단을 물을 때**("꿰매야 하나요", "응급실 가야 할까요", "먹여도 되나요" 등):
  "여기서는 진단을 받을 수 없어요" / "글을 읽는 분들은 의사가 아닙니다. 증상은 병원에 전화로 물어보세요."
  - 연빨강 "위급하면 지금 119 전화" → 그 위에 "119에 전화할까요?" 확인 시트
  - [그대로 올리기](주)
  - "고쳐 쓰기"
- 둘 다 해당하면 전화번호를 먼저 묻는다
- 걸리지 않는 글(문 연 곳 묻기·다녀온 이야기)은 시트 없이 바로 올라간다

## 글 아래
- "신고" → **"신고하기"**(14px, 진한 회색). 누른 뒤 흐름은 그대로(이유 고르기 → 즉시 격리)

## 음성 입력
- 끝맺음이 **분명히 묻는 말**일 때만 "?"를 붙인다("있나요"·"할까요"·"인가요" 등)
- "."는 자동으로 붙이지 않는다. "열이 나요"·"어디 다녀왔어요"·"병원 가요"는 그대로
- "물음표·마침표·쉼표·느낌표"라고 말하면 부호로 바뀐다
