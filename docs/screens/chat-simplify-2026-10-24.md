# 현장톡 첫 화면 단순화 (2026-10-24)

목표: /chat 에 들어오면 안내가 아니라 작성창과 글이 먼저 보인다.
로컬 `next start` + 크롬 headless 로 찍어 확인했다. headless 의 최소 폭이 약 500px 이라
**360px 은 실측하지 못했다** — 아래 높이는 그보다 넓은 폭 기준의 근삿값이다. **실기기 미확인.**

## 접힘 (기본)

```
← 💬 실시간 현장톡                  더보기  [📞 119]   ← 머리띠 119 는 항상 보인다(확인 창 그대로)
[ ℹ️ 안내 보기                          ●  ▾ ]        ← 44px, 처음 온 사람에게만 파란 점
┌ 묻거나 알려주기 ───────────────────────┐
│ 🎤 눌러서 말로 입력하기                  │
│ [ 입력칸 ]                               │
│ 지역 없이 · ○○ 이름으로 올라갑니다        │
│ 진단·치료 조언, 의료기관 비방·욕설은…     │
│ [            올리기            ]         │   ← 740px 높이 화면에서 첫 화면 안(약 640px)
└──────────────────────────────────────────┘
[ 상황 공유하기 ]                                     ← 작성창 아래로 옮김
[ 최근 1개월 | 이전 글 ]  내 지역 고르기                ← 목록 바로 위로 옮김
┌ 대화 ─ 빠른 반응 안내 · 글 목록 ┐
```

## 펼침 ("안내 보기" 누름)

줄 글자가 "안내 접기 ▴"로 바뀌고(`aria-expanded="true"`) 그 아래에 **문구 그대로** 세 덩어리:
1. 베타 — "베타로 운영 중입니다. 아직 글이 많지 않습니다. 확실하지 않을 때는…"
2. 노란 유의 박스 — `USER_REPORT_DISCLAIMER` 그대로
3. 케타 말풍선 — "AI 아님 · 정해진 안내만 해요" / "주변 분들이 눌러 준 빠른 반응으로…급하면 119." / [🚑 위급하면 기다리지 말고 119 전화] → "119에 전화할까요?" 확인 창

한 번 열면 점이 사라지고 이 브라우저에 기억한다(localStorage `caretime_chat_guide_opened`).
저장소를 못 쓰면 다음 방문에 점이 다시 보일 뿐이다.

## 상태별

| 상태 | 화면 |
|---|---|
| 빈 방 | 안내 보기 줄 → 빈 방 안내(EmptyRoomLead) → 작성창. 공유·조건·대화 칸 없음(전과 같다) |
| 조회 실패 | 대화 칸에 "글을 불러오지 못했습니다… 올라온 글이 없다는 뜻은 아닙니다." (전과 같다) |
| 글 0건(조건 걸림) | "○○에는 아직 글이 없어요…" + [전국 글 보기] (전과 같다) |
| 작성 기능 닫힘 | 작성창 자리에 닫힘 안내, 그 아래 공유·조건·목록 |

올리기 전 확인 시트(전화번호·진단 요구)는 그대로다.
