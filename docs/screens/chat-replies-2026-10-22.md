# 현장톡 답글 (2026-10-22)

로컬 Supabase(migration 20261022 를 **로컬에만** 적용)에서 서버 라우트를 실제로 왕복한
테스트(`tests/guestWrites.realtime.test.ts` "답글")와, 컴포넌트를 서버 렌더한 마크업
테스트(`src/components/chat/replies.test.tsx`)로 확인했다. **실기기 미확인.**
아래 그림은 그 마크업을 글로 옮긴 것이다.

## 닫힌 카드 — 줄이 늘지 않는다

```
(본문)
다정한잣나무4045 · 강서구
사용자 공유 · 미확인
( 👍 대기 3명 이하 ) ( 🩺 선생님 계심 ) ( ⚠️ 접수 마감됨 )
💬 답글 2개                                      신고   공유     ← 기존 줄에 들어감
```

- 내 글: `💬 답글 2개 [새 답글 1개]` — 파란 배지. 남의 글에는 배지가 없다.
- 답글 0개: `💬 답글 0개`. "첫 답글을 남겨 주세요"는 **펼친 뒤에만**.
- **답글을 못 읽으면 버튼이 없다.** 화면이 migration 보다 먼저 배포됐거나 조회가 실패한 경우.
  첫 그림(서버 렌더)에도 없다 — 숫자를 모르는 채로 "0개"를 그리지 않는다.

## 펼친 카드

```
💬 답글 2개                                      신고   공유
│ ┌───────────────────────────────────────────┐
│ │ 방금 다녀왔는데 대기 없었어요               │   ← 연한 바탕, 15px
│ │ 차분한수리4363  3분 전              신고   │   ← 14px, 남의 답글만 신고
│ └───────────────────────────────────────────┘
│ ┌───────────────────────────────────────────┐
│ │ 감사해요                                    │
│ │ 다정한잣나무4045 · 내 답글  방금 전          │   ← 내 답글은 신고 없음
│ └───────────────────────────────────────────┘
│ 답글 쓰기
│ [                                          ]   ← 16px 입력칸
│ 직접 확인한 사실만 적어 주세요. 진단이나 치료 판단은 적지 않습니다.
│ [            답글 올리기            ]          ← 44px
```

빠른 문구 버튼(지금 열려 있어요 등)은 **없다**(2026-10-22 결정 — 짧은 답은 반응 칩이 맡는다).

## 상태별

| 상태 | 펼친 영역에 보이는 말 |
|---|---|
| 읽는 중 | "답글을 불러오는 중이에요" |
| 답글 0건 | "첫 답글을 남겨 주세요" + 작성칸 |
| 읽기 실패(펼친 뒤) | "답글을 불러오지 못했어요. 잠시 후 다시 열어 주세요." — "없음"과 다른 말 |
| 답글 수 읽기 실패 | 답글 버튼 자체가 없다 |
| 작성 기능 닫힘(`NEXT_PUBLIC_FIELD_TALK_LIVE`) | 목록만, 작성칸 없음 |
| 쓰기 닫힘(`CARETIME_WRITES=closed`) | 작성칸은 보이고 올리면 "보내지 못했습니다…"(서버 503) |
| 거절(개인정보·욕설·같은 내용) | 서버가 적어 보낸 이유를 그대로(작성창과 같다) |
| 제한(10초 1건 등) | "잠시 후 다시 보낼 수 있습니다." |
| 부모 글이 내려감 | 답글 뷰가 함께 숨긴다. 그 글에 새 답글을 달면 "답글을 달 수 없는 글입니다…" |
| 답글 신고 | 그 자리에서 목록에서 빠지고 서버가 바로 내린다 |
