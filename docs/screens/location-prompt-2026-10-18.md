# 접속 시 위치 권한 요청 (2026-10-18)

코드·테스트·빌드로 확인했다. 휴대폰 확인 방법은 PR 본문에 있다.
**방침 1-5 문구가 바뀌었다 — 검토 대기(전문가 확인 전).**

## 홈 (지역을 아직 안 고른 사람)
- 화면이 열리면 **바로 휴대폰의 위치 권한 창**이 뜬다(지도 키가 있을 때만. 없으면 아무 일 없음)
  - 허락 → 지역이 채워지고 "어느 지역에 계세요?" 카드가 현장톡 배너로 바뀐다
  - 거부 → 다시 묻지 않는다. 카드 그대로, 직접 고르면 된다
  - 그냥 닫음 → 같은 탭에서는 다시 띄우지 않는다(홈 → 현장톡으로 가도 안 뜬다).
    새로 열면 다시 묻는다. "물었다"는 기록은 메모리에만 있고 기기에 저장하지 않는다
- 찾은 이름이 우리 목록과 맞지 않거나 지도 서비스를 못 불러오면 조용히 끝난다. 카드 그대로

## 현장톡 (지역이 비어 있는 사람)
- 홈과 같다. 채워지면 토스트 "지역을 내 위치(○○)로 골랐어요. 작성창에서 바꿀 수 있어요."
- 같은 탭에서 홈에서 이미 물었으면 다시 묻지 않는다

## 지역을 이미 고른 사람
- 아무것도 묻지 않는다(전과 같다)

## 바뀌지 않은 것
- "내 위치로 선택" 버튼, 그 아래 "위치는 지역 이름을 찾는 데만 쓰고 저장하지 않습니다"
- 좌표는 기기에서 카카오로만 간다. 권한을 거부하면 카카오 SDK 를 받지 않는다
