2026-10-18 판(`location-prompt-2026-10-18.md`)에서 바뀐 것만 적는다.
**방침 1-5 문구 변경은 여전히 검토 대기(전문가 확인 전).**

## 현장톡 (지역이 비어 있는 사람)
- 화면이 열리면 휴대폰의 위치 권한 창이 뜬다(전과 같다)
  - 허락 → 찾으면 지역이 채워지고 토스트 "지역을 내 위치(○○)로 골랐어요. 작성창에서 바꿀 수 있어요."
  - 거부 → **아무 말 없이** 끝난다. 다시 묻지 않는다. 작성창에서 직접 고르면 된다
  - 허락했는데 못 찾음 → **새로 토스트 한 줄**. 화면은 막지 않는다
    - 시간 초과(10초): "위치를 찾는 데 너무 오래 걸립니다. 직접 골라 주세요."
    - 지도 도구를 못 받음(오류 또는 8초 무응답): "지도 서비스를 불러오지 못했습니다. 직접 골라 주세요."
    - 이름으로 못 바꿈(오류 또는 8초 무응답): "지역 이름을 찾지 못했습니다. 직접 골라 주세요."
    - 받은 이름이 목록과 안 맞음: "지역(동네) 이름을 알아보지 못했습니다. 직접 골라 주세요."
- 전에는 지도 도구가 응답 없이 멈추면 끝없이 기다렸다(화면은 안 막혔지만 끝나지도 않았다)
- 인앱 브라우저(카카오톡·네이버·인스타그램·페이스북·라인·다음 앱)이고 아직 허락 전 → **묻지 않고**
  토스트 "이 앱 안에서는 위치를 찾지 못할 수 있어요. 크롬 등으로 열어 주세요." 이미 허락돼 있으면 그대로 찾는다
- 작성창의 [내 위치로 선택] 아래에도 인앱이면 같은 한 줄이 보인다(버튼은 그대로 — 앱에 따라 뜨는 경우가 있다)

## 홈 (지역을 아직 안 고른 사람)
