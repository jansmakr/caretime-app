# 빠른 반응 칩을 누르는 버튼으로 (2026-10-22)

운영 빌드(`next start`)를 로컬 Supabase 에 붙여 `/chat` 을 두 세션(글쓴이 A, 다른 사람 B)으로
읽고 적었다. B 가 "선생님 계심"을 누른 뒤의 상태다. 서버가 그린 첫 그림(HTML)을 옮긴 것이고,
마운트 뒤에만 그려지는 것(방 안내, 누른 표시 복원)은 따로 표시했다.

## 왜

칩(대기 3명 이하 · 선생님 계심 · 접수 마감됨)이 테두리 없는 회색이라 옆의 주제 표시와 구분이 안 됐고,
무엇을 하는 칩인지 말하는 곳이 없었다. 또 숫자가 서버와 어긋났다:
새로고침하면 누른 표시가 사라지고, 다시 누르면 화면 숫자만 1 올랐다(서버는 중복이라 받지 않음).
다시 누르면 화면에서만 내려가는 취소도 있었다.

## 남의 글 (B 가 본 화면)

```
대화                                                    1건
┌──────────────────────────────────────────────────┐   ← 마운트 뒤, 닫지 않은 경우만
│ 글 아래 버튼은 현장 상황을 알려 주는 빠른 반응이에요.  ✕ │
│ 아시면 눌러 주세요.                                  │
└──────────────────────────────────────────────────┘
방금 전
(본문)
다정한잣나무4045 · 강서구
사용자 공유 · 미확인
( 👍 대기 3명 이하 ) ( 🩺 선생님 계심 1 ) ( ⚠️ 접수 마감됨 )   ← 테두리 있는 버튼 3개
신고   공유
```

- 첫 그림에서는 세 칩 모두 `aria-pressed="false"` 다. B 가 누른 "선생님 계심"은 마운트 뒤
  `GET /api/field-reports/reactions` 응답이 오면 ✓ 와 파란 바탕으로 바뀐다.
- 눌린 칩: 이모지 자리에 ✓, 상태색 바탕 + 2px 테두리. 다시 누르면 칩 아래 "이미 알려 주셨어요"(4초).
- 실패 시 칩 아래 한 줄: "너무 자주 누르셨어요. 잠시 후 다시 눌러 주세요." / "보내지 못했어요. 잠시 후 다시 눌러 주세요."
  — 표시와 숫자는 되돌린다.

## 내 글 (A 가 본 화면)

```
내 글                                                방금 전
(본문)
다정한잣나무4045 · 강서구
사용자 공유 · 미확인
다른 분들이 눌러 준 반응이에요
[🩺 선생님 계심 1]                                        ← 버튼 아님. 받은 것만
삭제   공유
```

받은 반응이 0건이면 칩 없이 한 줄: **"아직 다른 분들의 반응이 없어요"**.
A 가 요청을 직접 보내 자기 글에 누르면 서버가 `403 {"error":"own_post"}` 로 막는다(확인함).

## 상태별

| 상태 | 무엇이 보이나 |
|---|---|
| 글 0건(빈 방) | 기존 그대로(`EmptyRoomLead`). 방 안내 없음 — 누를 칩이 없다 |
| 조회 실패 | 기존 문구 그대로. 방 안내 없음(글이 없으므로) |
| 내 글만 있음 | 방 안내 없음. 내 글 카드에 위 한 줄 |
| 안내를 닫음 | 이 브라우저에서 다시 안 보임(localStorage `caretime_reaction_guide_closed`). 저장소를 못 쓰면 다시 보임 |
| 내 반응 읽기 실패·제한 | 누른 표시가 복원되지 않을 뿐. 다시 누르면 서버가 `already` → "이미 알려 주셨어요", 숫자는 그대로 |
