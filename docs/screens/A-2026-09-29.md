## 상태별 문구 — 셋을 구분한다

| 상태 | 문구 |
|---|---|
| 서버 조회 실패 | 글을 불러오지 못했습니다. 잠시 후 다시 열어 주세요. **올라온 글이 없다는 뜻은 아닙니다.** |
| 조건에 걸려 0건 | 이 조건에 올라온 글이 아직 없습니다. 위에서 첫 글을 남겨 보세요. |
| 진짜 0건 | 아직 올라온 글이 없습니다. 지금 상황을 물어보거나 알려 주세요. |

전에는 셋이 한 문장이었다. 서버가 죽은 날에도 "아직 올라온 글이 없습니다"라고 말했고,
그건 사실이 아니다.

## 가짜 글 — 없음

운영 빌드 HTML 을 문자열로 검사했다.
`가상아이봄` `가상한빛` `강서구맘` `야간지킴이` `봉합 접수가 가능` 전부 없음.

## A 시점에 남은 문제 (B/C 에서 푼다)

1. **DEMO 배너가 맨 위다.** "모두 가상 데이터"라고 말한 바로 아래에서 진짜 글을 쓰라고
   한다. 병원 목록이 실제로 가상이라 문구가 거짓은 아니지만, 첫 작성자에게는
   "여기 쓰는 것도 가짜"로 읽힌다.
2. **0건인데 [상황 공유하기]가 두 번째 요소다.** 공유할 것이 없는 방을 공유하라고 한다.
3. **왜 비었는지 말하지 않는다.** 막 시작했다 / 고장났다 / 아무도 안 쓴다를 구분할 수 없다.
   출시 직후 0건은 정상인데 화면은 그것을 고장처럼 보이게 한다.
4. **필터 3개가 고를 것 없는 상태로 먼저 보인다.**
5. **검색 결과·병원 상세에서 현장톡으로 가는 링크가 없다.** 유일한 경로는 하단 내비다.
