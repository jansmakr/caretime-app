# B/C 직후 화면 — 2026-09-29

운영 빌드를 띄워 HTML 에서 텍스트를 뽑았다.
`/search` 는 정적 라우트라 SSR HTML 에 목록이 없다(병원 조회가 클라이언트에서 돈다).
그래서 그 화면은 **판정 조건으로** 확인했고, 픽셀로 확인하지 않았다 — 아래에 적어 둔다.

## /chat — 빈 방 (출시 직후의 상태)

```
💬 실시간 현장톡

유의  본 정보는 방문 환자·보호자의 자율 공유 데이터이며 …

아직 아무도 글을 남기지 않았어요
현장톡이 막 열렸습니다. 고장이 아니라 아직 첫 글이 올라오지 않은 것입니다.

지금 병원에 계신다면, 본 것을 한 줄만 남겨 주세요.
뒤에 오는 보호자가 헛걸음을 덜 합니다.

  · 방금 접수했는데 앞에 3명 대기라고 해요
  · 지금 봉합 가능한지 물어보신 분 계신가요?
  · 화상 처치는 오늘 어렵다고 안내받았어요

로그인 없이 바로 올라갑니다. 이름·연락처는 저장하지 않습니다.

현장 상황 묻기 · 답하기
직접 확인한 사실만 적어 주세요. 진단이나 치료 판단은 적지 않습니다.
[찢어진 상처] [화상] [그 밖의 상처]
  · 지금 봉합 가능한가요?
  · 소아도 진료되나요?
  · 대기 얼마나 되나요?
이름·연락처처럼 개인을 알 수 있는 정보는 적지 마세요.       41 / 300
올라갈 위치: 지역 미지정
지역을 고르지 않아도 올라갑니다. 어느 병원인지는 글에 적어 주세요.
[ 보내기 ]
```

A 와 달라진 것:

- **공유 버튼을 내렸다.** 공유할 글이 없는 방을 공유하라고 하지 않는다.
- **조건 고르는 줄을 내렸다.** 고를 것이 없다. 첫 글은 지역을 고르지 않고도 쓸 수 있다.
- **"대화 0건" 섹션을 내렸다.** 위의 안내가 이미 그 말을 하고 있다.
- 이 화면의 결정이 하나가 됐다 — 첫 글을 쓴다(원칙 1).

작성창 안내가 같이 바뀐다. 조건 줄을 감췄으므로 "위에서 지역·병원을 고르면"은
가리킬 곳이 없는 말이 된다. 화면에 실제로 있는 것만 가리켜야 한다.

## /chat — 조건을 걸어서 0건

빈 방이 아니다. 조건 줄과 공유 버튼이 그대로 있고, 목록 자리에 이렇게 적힌다.

```
이 조건에 올라온 글이 아직 없습니다. 위에서 첫 글을 남겨 보세요.
[ 전체 보기 ]
```

조건을 되돌릴 길을 막지 않는다. "글이 없다"와 "이 조건에 없다"는 할 일이 다르다.

## /chat — 서버 조회 실패

```
글을 불러오지 못했습니다. 잠시 후 다시 열어 주세요.
올라온 글이 없다는 뜻은 아닙니다.
```

빈 방 화면을 쓰지 않는다. 실패를 "아직 아무도 안 썼다"로 말하면 거짓이다.

## /hospital/[id] — 확인된 상태가 없을 때 (SSR 로 확인함)

```
현재 상태   [현재 상태 확인 필요]

상태가 확인되지 않았나요?
의료기관이 직접 확인한 정보가 없을 때는, 지금 그 병원 앞에 있는 보호자에게
물어볼 수 있습니다.
[ 현장톡 보기 ]
이용자끼리 나누는 정보입니다. 의료기관이 확인한 정보가 아닙니다.

[ 전화로 확인하기 ]
[ 목록으로 ]
```

상태가 확인돼 있으면 이 블록은 나오지 않는다 — 답이 이미 화면에 있다.
전화를 대신하지도 않는다. 전화 버튼은 그대로 주 버튼이다.

## /search — 판정 조건으로만 확인함

정적 라우트라 SSR HTML 에 목록이 없다. 브라우저에서 픽셀로 확인하지 않았다.
확인한 것은 조건이다.

| 상황 | 조건 | 보이는 것 |
|---|---|---|
| 결과 0건 | `results.length === 0` | 안내 + `FieldTalkExit variant="empty"` |
| 결과는 있는데 전부 미확인 | `results.every(m => m.hospital.liveStatus === null)` | 목록 + `FieldTalkExit` |
| 확인된 상태가 하나라도 있음 | — | 목록만 |

지금 시드에서는 `service_statuses` 가 비어 있어 모든 병원의 `liveStatus` 가 null 이다.
즉 **참여 병원이 0곳인 동안 두 번째 줄이 기본 화면이다.** 그래서 이 출구가 필요하다.

## 남은 것

1. **DEMO 배너가 여전히 맨 위다.** 병원 목록이 실제로 가상이라 문구가 거짓은 아니지만,
   첫 작성자에게는 "여기 쓰는 것도 가짜"로 읽힌다. 실제 공공데이터 병원을 넣어야
   떼어낼 수 있다 — 별도 작업이고 사용자 판단이 필요하다.
2. `/search` 를 브라우저에서 눈으로 확인하지 않았다.
3. 현장톡 목록 필터가 클라이언트 필터다. 서버가 준 최근 100건 안에서만 거른다.
