# 베타에서 확인할 것

**실제 휴대폰으로, 실제 운영 주소에서 한다.** 로컬에서 되는 것은 이미 테스트가 본다.
여기서 보려는 것은 테스트가 볼 수 없는 것 셋이다 — 손으로 쓰는 감각, 빈 화면이
사람을 움직이는지, 그리고 신고가 들어온 밤에 실제로 작동하는지.

막히면 **그 자리에서 적는다.** 나중에 기억으로 적으면 "좀 느렸다" 같은 말이 남고
그건 고칠 수 없다.

---

## 1. 실제 휴대폰에서 글이 써지는가

| | 확인 | 무엇을 보면 실패인가 |
|---|---|---|
| ☐ | 주소를 받아 `/chat` 을 연다 | 흰 화면, 느려서 기다리게 됨 |
| ☐ | **로그인 화면이 한 번도 안 나온다** | 로그인·가입·인증 요구 |
| ☐ | **지역·병원을 고르지 않고** 바로 쓴다 | 고르라고 막음, 무엇을 골라야 하는지 모르겠음 |
| ☐ | 보내기를 누른 뒤 **1~2초 안에** 목록 맨 위에 올라온다 | 아무 반응 없음, 두 번 누르게 됨 |
| ☐ | **새로고침해도 남아 있다** | 사라짐 (= 서버에 안 갔다) |
| ☐ | 내 글에 `내 글` 표시와 `삭제` 가 보인다 | 없음 (= 누가 썼는지 서버가 모른다) |
| ☐ | **다른 기기**(또는 시크릿 창)에서 그 글이 보인다 | 안 보임 |
| ☐ | 두 기기를 **동시에** 열어 두고 한쪽에서 쓰면 **새로고침 없이** 다른 쪽에 올라온다 | 새로고침해야 보임 (= 실시간이 끊겼다) |
| ☐ | 다른 기기에는 `신고` 가 보인다 (내 글에는 `삭제`) | 내 글에 신고가 보이거나 그 반대 |

## 2. 빈 방에서 첫 글이 나오는가

**가장 답을 모르는 항목이다.** 출시 직후에는 반드시 0건이고, 그 한 화면이 이 기능의
전부다. 숫자로 확인할 수 없으니 읽고 느낀 것을 적는다.

| | 확인 | 무엇을 보면 실패인가 |
|---|---|---|
| ☐ | 글이 0건인 `/chat` 을 처음 보는 사람처럼 읽는다 | "고장났나?" 로 읽힘 |
| ☐ | 왜 비어 있는지 화면이 설명한다 | 왜 빈지 모름 |
| ☐ | **무엇을 쓰면 되는지 알겠다** | 빈 칸을 보고 멈춤 |
| ☐ | 작성창이 **상처 질문으로 시작하지 않는다** (기본 칩 '그 밖의 상황', 본문 비어 있음) | 봉합·화상 질문이 미리 채워져 있음 |
| ☐ | 주제를 **비워도** 보낼 수 있다 | 주제를 요구함 |
| ☐ | 아는 사람 1~2명에게 주소만 주고 **설명 없이** 글을 쓸 수 있는지 본다 | 무엇을 하는 곳인지 물어봄 |

## 3. 신고·격리·복구가 도는가

밤에 들어오는 일이다. 격리는 자동이지만 **복구는 사람이 한다.** 그 경로를 한 번
끝까지 걸어 본다. 질의는 [OPS-moderation.md](OPS-moderation.md) 에 있다.

| | 확인 | 어떻게 |
|---|---|---|
| ☐ | 다른 기기에서 내 글을 **신고**한다 | 글 아래 `신고` → 이유 고르기 |
| ☐ | **즉시** 목록에서 사라진다 (양쪽 기기 모두) | 새로고침 없이 사라져야 한다 |
| ☐ | 격리 기록이 남았다 | `select action, reason_code from moderation_actions order by created_at desc limit 1;` → `QUARANTINE` / `auto_on_report` |
| ☐ | **콘솔에서 복구**된다 | OPS-moderation ③ 「복구한다」 |
| ☐ | 복구 뒤 24시간 안의 글이면 목록에 돌아온다 | 돌아오지 않으면 `public_until` 이 지난 글이다(그 경우는 정상) |
| ☐ | **본인 글 삭제**가 된다 | `삭제` → `지운다`. 양쪽 기기에서 사라진다 |
| ☐ | 지운 글은 `내 글 목록`에서도 빠진다 | 새로고침 후 그 글에 `삭제` 가 없다 |
| ☐ | **전화번호가 막힌다** | 본문에 `010-1234-5678` 을 넣고 보내기 → 거절 문구 |
| ☐ | 주민등록번호 모양도 막힌다 | `990101-1234567` → 거절 |
| ☐ | 연달아 보내면 막힌다 | 바로 한 번 더 보내기 → "N초 후" |

확인에 쓴 글은 **전부 지운다.** 가짜 글을 남기지 않는다.

## 덤으로 보면 좋은 것 (셋에 넣지 않았다)

- **24시간 뒤** 그 글이 목록에서 사라지는가 (공개 종료). 지워진 것이 아니라
  공개가 끝난 것이다 — 30일 뒤에 삭제된다
- **다음 날 아침** `select * from public.purge_health();` 의 `last_run_at` 에 시각이
  찍혔는가. 비어 있으면 크론이 안 돈 것이다
- 주마다 `select count(*) from reports where state in ('OPEN','REVIEWING')
  and created_at < now() - interval '7 days';` → 0 인가 (OPS-moderation ①)

## 베타를 끝내는 조건 — 날짜가 아니다

정식 출시 날짜를 두지 않는다. 지금 상태가 실제로 베타다(등록 의료기관 2곳,
참여 의료기관 0곳, 공공데이터 미연동). 베타 표시를 떼는 것은 **등록된 의료기관이
"아직 적습니다"라고 적지 않아도 될 만큼 늘었을 때**다.

스위치는 셋이고 서로 따로 있다. 하나를 바꿀 때 다른 것이 따라 바뀌지 않는다.

| 스위치 | 무엇을 묻는가 | 지금 |
|---|---|---|
| `isBeta` | 서비스 단계가 베타인가 | `true` |
| `isSearchIndexingOpen` | 검색엔진에 색인시키는가 | `false` |
| `isDemoContentAllowed` | 가짜 데이터를 낼 수 있는가 | 운영에서 `false` |
